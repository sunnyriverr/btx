## Failure and correction

The published Linux archive `796b9edd` could start its node, but Atlas failed before opening on Ubuntu24.04: its bundled GLib required GLIBC2.43. Rebuilt GUI inputs produced candidate `03fc6161`, which opened and connected, but the unchanged archive checker still rejected two ownership mismatches: Qt-private GLib/DBus copies unused by Atlas, and a directly executed guard without a packaged-library RUNPATH.

Follow direct ELF dependencies rather than flattened ldd descendants; leave host GTK/GLib-family/DBus services on the host. Keep the remaining Qt closure private, with explicit launcher/config/plugin paths. Preserve libraries shared by non-GUI executables in root lib using those consumers’ authoritative inputs. Give the direct guard `$ORIGIN/../lib` before creating its regular hard-linked sibling. OpenSSL is preserved. Checker bytes and acceptance rules are unchanged.
